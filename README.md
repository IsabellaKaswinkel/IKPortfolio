## Publishing on GitHub Pages
1. Create a new public repo on your GitHub (e.g. `IsabellaKaswinkel.github.io` for a clean root URL, or any repo name if you're fine with a `/repo-name/` path).
2. Upload `index.html`, `Isabella_Kaswinkel_Resume.pdf`, and `headshot.jpeg` into the repo (drag-and-drop on github.com works, or `git push`).
3. Go to the repo's **Settings → Pages**, set the source branch to `main` and folder to `/ (root)`, save.
4. Your live URL will be `https://IsabellaKaswinkel.github.io` (or `https://IsabellaKaswinkel.github.io/repo-name`) — it takes a minute or two to go live.
5. Test the link on your phone before submitting — the nav collapses into a hamburger menu under 800px width, and everything else reflows to a single column.
